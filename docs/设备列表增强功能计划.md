# 设备列表增强功能开发计划

## 功能需求
1. 设备列表增加上下移动按钮，可以调整顺序
2. 点击列表项时等同点击连接按钮

## 实现方案

### 1. 修改数据模型
- 在 Device.java 中添加排序字段 `order`
- 修改 DbHelper.java 数据库表结构支持排序字段

### 2. 修改布局文件
- 在 item_devices_item.xml 中添加向上和向下移动按钮
- 调整布局使按钮显示在适当位置

### 3. 修改适配器
- 在 DeviceListAdapter.java 中：
  - 点击列表项触发连接设备
  - 添加向上/向下移动按钮的点击事件
  - 实现设备顺序调整并保存到数据库
  - 列表数据按 order 字段排序
