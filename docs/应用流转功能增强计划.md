# 应用流转功能增强计划

## 任务目标
增强应用流转功能，支持：
1. 选择系统应用（当前只支持用户应用）
2. 支持应用筛选（用户应用/系统应用/全部）
3. 支持复制设备功能
4. 支持通过名称筛选应用

## 当前实现分析

### Server端 (Channel.java)
- `getAllAppInfo(int appType)` 方法：
  - appType=0: 返回全部应用
  - appType=1: 返回用户应用（排除系统应用）
  - appType=2: 返回系统应用（排除用户应用）
- 当前客户端只调用 appType=1（只获取用户应用）

### Client端 (Client.java)
- `getAppList(Device device, UsbDevice usbDevice)` 方法只调用 `app_type=1`

### UI端 (PublicTools.java)
- `createAddDeviceView` 方法提供应用选择功能
- 当前只有"扫描"按钮，没有筛选选项

## 实施方案

### 1. 修改Server端
- 无需修改（已支持app_type参数）

### 2. 修改Client端
- 修改 `getAppList` 方法，增加 appType 参数
- 支持获取不同类型的应用列表

### 3. 修改UI端
- 在item_add_device.xml中添加应用类型筛选单选按钮组
- 修改扫描逻辑，支持筛选
- 添加复制设备按钮
- 添加应用名称搜索过滤功能

### 4. 复制设备功能
- 在设备列表添加复制设备功能
- 复制时复制所有配置（包括specified_app）

## 修改文件清单
