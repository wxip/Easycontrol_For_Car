# 多开打包计划

## 目标
使用Gradle一键打包，一次性构建出四个不同包名的APK，用于应用多开（多账户同时在线）。

## 现有配置分析

- **当前包名**: `top.eiyooooo.easycontrol.app`
- **当前版本**: 1.6.10 (versionCode: 10610)
- **构建工具**: Gradle 8.3.0
- **输出目录**: `output/`

## 方案设计

### 多开包名方案
| 渠道 | 包名 | 应用名 |
|------|------|--------|
| official | top.eiyooooo.easycontrol.app | EasyControl |
| x1 | top.eiyooooo.easycontrol.app.x1 | EasyControl X1 |
| x2 | top.eiyooooo.easycontrol.app.x2 | EasyControl X2 |
| x3 | top.eiyooooo.easycontrol.app.x3 | EasyControl X3 |

### 实现方式
使用Gradle的`productFlavors`配合`applicationIdSuffix`来实现多渠道打包。

### Gradle任务
在 `app/build.gradle` 中定义以下任务：

| 任务名 | 说明 |
|--------|------|
| `generateKeystore` | 生成签名密钥库（首次运行自动执行） |
| `assembleAllRelease` | 构建所有flavor的Release版本 |
| `copyApksToOutput` | 复制APK到output目录 |

### 签名配置
签名配置存储在 `docs/signing.properties`：
- 首次运行 `assembleAllRelease` 时自动生成密钥库
- 密钥库位置: `easycontrol/release.keystore`

## 使用方法

```bash
cd easycontrol

# 方式1：一键打包（推荐）
./gradlew assembleAllRelease copyApksToOutput

# 方式2：分步执行
./gradlew assembleOfficialRelease assembleX1Release assembleX2Release assembleX3Release
./gradlew copyApksToOutput

# 或一次性执行
./gradlew generateKeystore assembleAllRelease copyApksToOutput
```

## 执行步骤

1. 修改 `app/build.gradle`，添加多渠道配置和Gradle任务
2. 配置签名文件 `docs/signing.properties`
3. 运行 `./gradlew assembleAllRelease copyApksToOutput` 打包
